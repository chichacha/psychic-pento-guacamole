山は、数式でできている。

12人の背景に、無限の風景をつくる。

Author

五マス研究室

山を描きたい。でも、山を一枚ずつ描く代わりに、数式に描いてもらうことはできるだろうか？

ここでは波を重ねて、山の輪郭をつくってみます。絵の才能は必要ありません。必要なのは、ちょっとした好奇心です。

1. 波をひとつ描いてみる。

まずは、横方向の位置を t = x / width で 0〜1 にそろえます。すると、画面が広くても狭くても同じ計算を使えます。

\[h_1(t) = A\sin(2\pi f_1t + \phi_1)\]

波を描く実験 🌊 スライダーを動かすと、数式が描く線も変わります。

  • 振幅（しんぷく / amplitude） \(A\)：波の高さ。数値を大きくすると、山は高く、谷は深くなる。
  • 周波数（しゅうはすう / frequency） \(f_1\)：横幅の中で波が何回繰り返されるか。数値を大きくすると、山と谷の数が増える。
  • 位相（いそう / phase） \(\phi_1\)：波の始まる位置。数値を変えると、波の形や高さはそのままで、左右にずれる。

波がゆっくり上下すると、大きくなだらかな丘になります。

2. 波を重ねてみる。

次は、もっと細かい波を足してみましょう。

最初の波 A は、大きくなだらかな丘。

そこに、少し細かい波 B を重ねると、小さな丘や谷が生まれます。

さらに、もっと細かい波 C を加えると、山の輪郭がでこぼこしてきます。

実は、3つとも同じ sin() という数式。違うのは、波の高さ（振幅）と、繰り返す回数（周波数）だけです。

大きな丘 ＋ 小さな丘 ＋ でこぼこ ＝ ちょっと山らしい形！

\[ h(t) = \underbrace{A\sin(2\pi f_1t+\phi_1)}_{\text{大きな丘}} + \underbrace{B\sin(2\pi f_2t+\phi_2)}_{\text{小さな丘}} + \underbrace{C\sin(2\pi f_3t+\phi_3)}_{\text{でこぼこ}} \]

大きな丘 + 小さな丘 + 細かなでこぼこ。 それぞれを別々に見てから、重ね合わせた形を観察できます。

4. 3つの波から、3つの山へ。

ここまで、3つの波を足して、ひとつの山の輪郭をつくりました。

でも、ゴマス村の風景には、山が1本しかないわけではありません。

遠くの山、中くらいの距離の山、手前の山。

実は、どの山も同じ数式から生まれています。

違うのは、波の高さ、繰り返す回数、始まる位置。そして、画面の中での高さです。

それぞれの山の輪郭を、次のように呼ぶことにします。

  • \(h_{\text{back}}(t)\)：遠くの山（遠景）
  • \(h_{\text{middle}}(t)\)：中くらいの距離の山（中景）
  • \(h_{\text{front}}(t)\)：手前の山（前景）

つまり、同じ数式を3回使って、3本の異なる輪郭をつくっているのです。

そして、遠くの山から順番に描いて、手前の山を重ねます。

ここには、2種類の「重ねる」があります。

  • 波を足す：3つの波を計算で足して、1本の山の輪郭をつくる。
  • 山を重ねる：3本の輪郭をそれぞれ塗りつぶして、遠くから手前へ描く。

波は数式の中で足し算。山は画面の上で重ね描き。

似ているようで、ちょっと違います。

5. 白帯から黒帯へ。

帯によって、山の色と険しさを変えることにしました。

白帯は、青みがかった穏やかな山。黄帯は、あたたかな黄金色の丘。黒帯は、深い森の色をした険しい山。

色だけでなく、細かな波の強さも変えています。

ただし、山の険しさは、本当のパズルの難易度を測定したものではありません。

これは、ゴマス村の風景を楽しくするためのデザイン上の約束です。

レベルを変えると、山の輪郭も少しずつ変わります。

ここでは、3つの役割を分けています。

  • 帯：色のパレットと基本の険しさ
  • レベル：山の形の変化
  • パズル番号：再現可能な山の個性

ちなみに、この実験室ではレベルとパズル番号を自由に組み合わせられます。実際のパズルでは、問題番号ごとにレベルが決まっています。

実験室だからこそ、同じ番号の山を、違うレベルで眺めてみることもできるのです。

6. 同じ山に、もう一度会える？

山の形を毎回完全にランダムに決めてしまうと、同じ風景にもう一度出会えるとは限りません。

そこで、パズル番号を乱数の種（seed）に使います。

この種から疑似乱数（ぎじらんすう / pseudorandom numbers）をつくって、波の位相（いそう）を決めています。

疑似乱数とは、ランダムに見えるけれど、決まった計算から生まれる数のこと。

例えば、波の位相を決めるために、こんな計算を使っています。

hash(seed * 101 + layer * 17 + component * 7919) * 2 * Math.PI

ここで、seed はパズル番号、layer は遠景・中景・前景の区別、component はどの波を計算しているかを表します。

101、17、7919は、入力を混ぜ合わせるために選んだ数字。特別な山の法則ではありません。

同じ番号・帯・レベル・設定なら、同じ風景を再現できます。

Math.random() は使いません。

偶然に見える。でも、偶然ではない。

7. 霧は何をしている？

遠くの山ほど、背景に近い色になり、輪郭が淡くなる。

こうした奥行きの表現を大気遠近法（たいきえんきんほう）といいます。

霧は、山の形そのものを変えません。

変えているのは、山の見え方です。

同じ3本の山でも、色の重なり方を変えるだけで、ずいぶん違う風景になります。

もちろん、霧の濃さはパズルの成績とは無関係です。

おわりに

ひとつの波から始めて、3つの波を足してみる。

できた輪郭を3本重ねて、色をつける。

そこに、パズル番号から生まれた疑似乱数と、少しの霧を加える。

すると、数式から風景が生まれました。

もちろん、これは地質学的な山のシミュレーションではありません。

数式を使った、ちょっと不思議な風景のデザインです。
