五色の虹は、本当にランダムなのか？

12人から選ぶ5人 — 順列と組み合わせの観察

Author

五マス研究室

研究の問い

data/solutions.csv には、12種類のペントミノの並びが記録されています。

今回は、そのうち 最後に登場する5人 に注目してみます。

同じ5人組は、どれくらいの頻度で登場するのでしょうか？ また、5人の並ぶ順番まで考えると、どんな違いが見えてくるのでしょうか？

ここで登場するのが、数学の2つの考え方です。

  • 組み合わせ（Combination）
  • 順列（Permutation）

誰が選ばれたか？

I・F・L・N・P と P・N・L・F・I は、 並び順が違っても同じ組み合わせです。

どの順番で並んだか？

I・F・L・N・P と P・N・L・F・I は、 異なる順列です。

今回の分析では、組み合わせは5人をアルファベット順に並べて表し、順列は元データに記録された順番をそのまま使います。

ひとつ注意！ データに記録された順番が、実際に人間がピースを置いた順番とは限りません。

🌱 豆知識：英語の語源

Combination はラテン語の combinare （結び合わせる）に由来します。

Permutation はラテン語の permutare （交換する、すっかり変える）に由来します。

「誰を組み合わせるか」と 「どう並び替えるか」。

言葉の成り立ちにも違いがあります！

## 向きや位置を除き、登場順だけを取り出す

各 `Answer` は、ペントミノを表す英字1文字と数字6桁（例：`Y060000`）の7文字を、12個つなげたものです。ここでは各記録の先頭の英字だけを取り出し、数字6桁は使いません。**元の並び順は変更しません。**

```{r}
#| label: parse-answer
expected_pieces <- sort(c("F", "I", "L", "N", "P", "T", "U", "V", "W", "X", "Y", "Z"))

extract_piece_sequence <- function(answer) {
  if (is.na(answer) || !str_detect(answer, "^(?:[FILNPTUVWXYZ][0-9]{6}){12}$")) {
    stop("Invalid Answer encoding: expected twelve letter + six-digit records")
  }
  starts <- seq(1L, 84L, by = 7L)
  pieces <- str_sub(answer, starts, starts)
  if (!identical(sort(pieces), expected_pieces)) {
    stop("Invalid solution: expected all twelve pentominoes exactly once")
  }
  pieces
}

rainbows <- solutions %>%
  mutate(
    piece_sequence = map(answer, extract_piece_sequence),
    last_five = map(piece_sequence, tail, 5L),
    permutation = map_chr(last_five, paste0, collapse = ""),
    combination = map_chr(last_five, ~ paste0(sort(.x), collapse = ""))
  )

rainbows %>%
  select(group_number, level, permutation, combination) %>%
  slice_head(n = 12) %>%
  knitr::kable(caption = "最後の5人：記録順とアルファベット順の比較")


```

```{r}
#| label: rainbow-helpers
#| echo: false

library(gt)
library(htmltools)

rainbow_swatch <- function(sequence, colors = character_colors) {
  pieces <- strsplit(sequence, "")[[1]]

  swatches <- vapply(pieces, function(piece) {
    color <- unname(colors[[piece]])

    sprintf(
      paste0(
        '<span title="%s" style="',
        'display:inline-block;',
        'width:36px;height:24px;',
        'background:%s;',
        'border-radius:4px;',
        'margin-right:3px;',
        'border:1px solid rgba(0,0,0,.08);',
        '"></span>'
      ),
      piece, color
    )
  }, character(1))

  paste0(
    '<span style="display:inline-flex;align-items:center;">',
    paste(swatches, collapse = ""),
    '</span>'
  )
}
```

例えば最初の解答の登場順は `r paste(rainbows$piece_sequence[[1]], collapse = " → ")` です。最後の5人を順番どおりに並べると `r rainbows$permutation[[1]]`、アルファベット順に並べると `r rainbows$combination[[1]]` になります。

## いちばんよく登場する虹

もっとも頻繁に登場した5人の組み合わせは **`r combination_counts$combination[[1]]`** で、`r combination_counts$n[[1]]` 件の解答に含まれていました。

```{r}
#| label: popular-rainbow
#| echo: false
#| results: asis

draw_rainbow <- function(sequence, colors) {
  pieces <- strsplit(sequence, "")[[1]]

  stopifnot(length(pieces) == 5)
  stopifnot(all(pieces %in% names(colors)))

  paths <- vapply(seq_along(pieces), function(i) {
    radius <- 240 - (i - 1) * 27

    sprintf(
      '<path d="M %d 270 A %d %d 0 0 1 %d 270"
         fill="none" stroke="%s" stroke-width="26"/>',
      300 - radius,
      radius,
      radius,
      300 + radius,
      unname(colors[[pieces[i]]])
    )
  }, character(1))

  svg <- paste0(
    '<svg viewBox="0 0 600 290" ',
    'xmlns="http://www.w3.org/2000/svg" ',
    'role="img" aria-label="五色の虹: ',
    sequence, '" ',
    'style="display:block;width:100%;max-width:700px;',
    'height:auto;margin:2rem auto;">',
    paste(paths, collapse = "\n"),
    '</svg>'
  )

  cat(svg, "\n")
}

draw_rainbow(
  combination_counts$combination[[1]],
  character_colors
)
```
