お祝いのしくみ

ひみつの実験室 · 実験002 の舞台裏

← お祝いシミュレーターに戻る

これは何のページ？

お祝いシミュレーターの裏側を、図とことばでのぞくページです。実際のゲームとは接続していない、ひみつの実験室の試作品です。

パズルが完成したとき、最後のピースや Hint・Check の回数をもとに、JavaScript がメッセージとお祝いの演出を組み立てています。

まずは、４つのお祝い

シミュレーターでは、Hint を使ったか？ と Check を使ったか？ の２つを見ています。

Hint Check お祝いのことば 登場するもの
0 0 ひらめいた！ 🍬 キャンディが大サービス（46個）
1回以上 0 助けてもらって、できた！ 🐛 いもむし + キャンディ（20個）
0 1回以上 たしかめながら、できた！ 🦋 ちょうちょ + キャンディ（20個）
1回以上 1回以上 じっくり、できた！ 🐛 いもむし + 🦋 ちょうちょ + キャンディ（20個）

どの組み合わせでも「完成おめでとう！」 という気持ちは同じ。ヒントやチェックを使ったからといって、失敗ではありません。

JavaScript はどうやって決めるの？

次の図は、assets/js/celebration.js の celebrate() が行っている分岐を、読みやすくしたものです。

ここで大事なのは、回数そのものではなく、0回か1回以上かでメッセージが決まること。たとえば Hint が1回でも8回でも、Check が0回なら「助けてもらって、できた！」になります。

コードの中心は、こんな考え方です。

const perfect = hints === 0 && checks === 0;

const messageKey = perfect
  ? "brilliant"
  : hints > 0 && checks > 0
  ? "both"
  : hints > 0
  ? "caterpillars"
  : "butterflies";

これは理解のために変数名を読みやすくした抜粋です。実際のコードでは h、c、key という名前を使っています。

ことばと演出は、別々に決まる

「どのことばを表示するか」を決めたあと、JavaScript は演出を作ります。

  • Hint が1回以上 → 地面にいもむしが登場。最大5匹まで表示し、それ以上は +3 のように残りの数を示します。
  • Check が1回以上 → 空中にちょうちょが登場。こちらも最大5匹まで描画します。
  • Hint も Check も0回 → キャンディの数が20個から46個に増えます。
  • どの場合も → キャンディの色は12人のペントミノの色から選ばれます。
レベルを変えると？

レベルはメッセージを変えません。キャンディの形の種類を変えます。

レベル キャンディの形
1–3 四角
4–6 四角・丸
7–8 四角・丸・ひし形
9–10 四角・丸・ひし形・キャンディ型

最後に置いたピースは？

「最後に置いたピース」を選ぶと、画面中央の五マスのキャラクターが変わります。

JavaScript は5つの正方形をSVGで描き、その上に小さな目と口をつけます。色と名前は data/characters.json から読み込みます。つまり、キャラクターを選んでも Hint × Check の判定は変わりません。

ことばはどこに書いてある？

お祝いの日本語と英語は、JavaScript の中に直接書き込むのではなく、data/celebration.json にまとめています。

"brilliant": {
  "ja": "ひらめいた！",
  "en": "Brilliant!"
}

JavaScript が brilliant などのメッセージキーを選び、選択中の言語に対応する文章を取り出します。翻訳がない場合は、設定された英語の文章にフォールバックします。

ファイルたちの役割

ファイル ひとことで言うと
experimental/celebration/index.qmd シミュレーターの画面を用意する
assets/js/celebration.js 入力を読み、条件を判断し、絵とことばを表示する
data/celebration.json 日本語・英語の文章や表示上限を保存する
data/characters.json 12人の色と名前を保存する
assets/css/celebration.css 配置、重なり順、動きを決める

「もう一回！」を押すと？

「完成！」と「もう一回！」は、どちらも celebrate() を呼び出します。現在の設定を読み直し、前の演出を消して、新しいキャンディやちょうちょを作り直します。

一方、スライダーやキャラクターを変更したときは、いったんプレビューをリセットします。新しい設定で「完成！」を押してみてください。
