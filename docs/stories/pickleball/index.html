ゴマス村ピックルボール部 🥒

遊びたい人、休みたい人、数えたい人。

ボールが一つ。コートが一面。

最初に集まったのは、たったの5人。

ところが、ダブルスで遊べるのは一度に4人だけ。

だれが休む？ だれと組む？ それって公平？

人数が増え、コートが増え、問題も増えていきます。

計算が好きな人も、おやつが気になる人も。

ゴマス村の住人たちは、今日も遊びながら考えます。

ちいさなコートの地図 🥒

実はコートの真ん中には キッチン（Kitchen） があります。どこかな？ 押してみよう。

コートは幅20フィート × 長さ44フィート。シングルスもダブルスも同じ大きさです。

公式のコート寸法に比例した図。周囲の安全スペースは含みません。

おはなし

第1話：5人なのに、コートは1面。

「ぼくは休みたくないです！」

5人でダブルス。休めるのは毎回1人だけ。

みんなが同じ回数遊んで、全員とペアになる方法は？

第1話を読む →

第2話：もう一人、来ちゃった。

「6人なら、もっと公平になりますか？」

休む人は毎回2人。3試合なら全員が1回ずつ休めます。

でも、全員と1回ずつペアになるのは、そう簡単じゃない。

第2話を読む →

第3話：休憩席が足りません。

「同じ回数、座れることも大事です。」

7人になって、休む人は毎回3人。

なのに、椅子は2つしかありません。

公平に遊ぶことと、公平に休むことは同じ？

第3話を読む →

第4話：コートが増えました。

「……おやつ休憩もゼロですか？」

8人目がやってきて、コートも2面に！

ついに全員が同時に遊べます。

そして、7ラウンドで28組のパートナーが勢ぞろい。

第4話を読む →

次のおはなし 🥒

第5話：ゼロ、ゼロ、ツー？

「まだ0点なのに、どうして2なの？」

ようやく試合が始まったゴマス村ピックルボール部。

ところが、最初のサーブから謎の数字が登場しました。

0–0–2って何？ サーブは誰から？ 点数はどう数えるの？

今度は、ピックルボールそのもののルールを探検します。

ただいま構想中。

その先のおはなし（いつか、たぶん）

  • ゴマス村ダブルス交流会。 — 12人全員が集まったら、どうやって遊ぶ？
  • 負けても、もう一試合。 — シングルス大会の公平って？
  • おやつ休憩は試合に含まれますか？ — 試合時間が違うと、休憩時間も違うらしい。
ちょっと気になる？ — 公平ってなんだろう

全員が同じ回数遊べば、公平？

全員と1回ずつペアになれば、公平？

座って休む人と、立って休む人は？

みんなが同じルールで遊んでも、公平だと感じるかどうかは、人によって違うかもしれません。

このシリーズでは、組み合わせの数学を楽しみながら、そんなこともちょっと考えてみます。

でも、いちばん大事なのは……

みんなが楽しく遊べること。

まんなかおじさんにとっては、おやつも大事です。
