きのこの部位 · Mushroom anatomy

ところで、みんなが作った「傘」は、きのこのどの部分なのでしょう？

English 日本語 どこ？
Cap / Pileus 傘（かさ） きのこの上の部分
Cap margin 傘の縁（かさのふち） 傘の外側
Gills / Lamellae ひだ 傘の裏にある放射状の板
Stem / Stipe 柄（え） 傘を支える部分
Ring / Annulus つば 種類によって柄につく輪
Spores 胞子（ほうし） 繁殖にかかわる細胞
Mycelium 菌糸体（きんしたい） 地中などに広がる菌糸のネットワーク

すべてのきのこに、ひだやつばがあるわけではありません。

ゴマス村の、どうでもいい大発見。🔎

柄は、え？ がら？

きのこの柄（え）は、傘を支える部分。

水玉やしま模様の柄（がら）は、デザインのこと。

つまり、同じ「柄」でも、読み方も意味も違います。

さらに英語では……

  • Stipe — きのこの柄（え）
  • Stripe — しま模様

たった一文字、r が増えるだけ。

「柄を長くしよう。」

「しま模様を長くするの？」

どうやら、会議が長引いた理由がわかってきました。

役に立つかどうかは、調べてから考えよう。

観察の約束： 野生のきのこは観察と写真撮影だけ。食べられるかどうかを見た目で判断したり、試食したりしません。

小さな数学のメモ： 傘の幅、高さ、曲率、模様の配置。少し数字を変えるだけで、まったく違う形が生まれます。この工房のきのこは、幾何学から生まれた架空のキャラクターです。
