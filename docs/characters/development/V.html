📐 Vおばさんの Seven V’s

かどっこおばさんは、お気に入りの角から世界を眺めて七つのVを見つけました。

角にいるからこそ、見えるものもあるようです。

V What it means
View まず角から景色を眺める。
Value 自分の落ち着く場所を大切にする。
Verify ここが本当にいい角か確かめる。
Venture ときには角の外へ出かけてみる。
Visit 別の角にもおじゃましてみる。
Variety 角が違えば、景色も違う。
Voice お気に入りの場所を自分の言葉で伝える。

View → Value → Verify → Venture → Visit → Variety → Voice
