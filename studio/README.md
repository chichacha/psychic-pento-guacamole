## PPGって何？

もともとの名前は **Psychic Pento Guacamole**。🥑

でも、Gの意味はひとつに決めなくてもいい。

- **Gravity** — なぜか引き寄せられる、五つの四角。
- **G-force** — くるくる回るFちゃんの遠心力。
- **Gomasu** — もちろん、五マス。
- **Gracias** — 一緒に遊んでくれる人たちへ。
- **Guacamole** — 理由は、まだない。

そして、もうひとつのPPG：

**Permanently Playful, Generally Undefined.**
