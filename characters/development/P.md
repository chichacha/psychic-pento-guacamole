## 🅿️ Pくんの Seven P's

ぎゅっとくんが、キャラクター開発の心得を7つにまとめてくれました。

本人は「Pで始まる言葉しか使ってはいけない」と思っているようです。

| P | What it means |
|---|---|
| **Play** | 遊び心から始める。 |
| **Personify** | 五つの四角に人格を与える。 |
| **Ponder** | この子なら、どうする？ |
| **Provoke** | ちょっと困らせてみる。 |
| **Prototype** | まず小さく作ってみる。 |
| **Publish** | 面白くなったら、みんなに見せる。 |
| **Preserve** | 残す価値のあるものだけ記録する。 |

**Play → Personify → Ponder → Provoke → Prototype → Publish → Preserve**
