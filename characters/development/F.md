## 🌪️ Fちゃんの Seven F's

くねくねちゃんも、7つの心得を考えてみました。

でも、本人はまだ7つで終わるつもりがありません。

| F | What it means |
|---|---|
| **Fidget** | じっとしていられない。 |
| **Flip** | ひっくり返してみる。 |
| **Find** | 新しい可能性を見つける。 |
| **Fail** | 失敗しても大丈夫。 |
| **Figure out** | どうしてそうなるか考える。 |
| **Follow** | 気になるものを追いかける。 |
| **Fly** | まだ知らない自分に会いに行く。 |

**Fidget → Flip → Find → Fail → Figure out → Follow → Fly**
