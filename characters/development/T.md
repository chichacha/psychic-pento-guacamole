## 📋 Tおばさんの Seven T's

しきりやおばさんは、もちろん七つのTにも順番をつけました。

問題は、ほかの住民がその順番を守るかどうかです。

| T | What it means |
|---|---|
| **Time** | まず集合時間を決めましょう。 |
| **Team** | 全員そろっているか確認！ |
| **Task** | それぞれの役割を決めます。 |
| **Tidy** | きちんと並べて、準備完了。 |
| **Track** | 進み具合を確認しましょう。 |
| **Trust** | ……たまにはみんなに任せてみる。 |
| **Together** | 予定と違っても、一緒なら大丈夫。 |

**Time → Team → Task → Tidy → Track → Trust → Together**

Tおばさん：「七つのT、全員確認！」

Fちゃん：「八つ目のTは？」

Tおばさん：「ないわよ！」

Fちゃん：「Try again!」
